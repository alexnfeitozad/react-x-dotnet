# React vs C# (Blazor) - Componentes e Estado

Este repositório é um guia prático comparando os conceitos de componentização do React (JavaScript) com o Blazor (C#).

## Projetos
- `react-basico`: Projeto React puro criado com create-react-app.
- `blazor-app`: Projeto C# criado com Blazor WebAssembly.

Ambos implementam o mesmo design de um "Armário" com Portas e Prateleiras.
